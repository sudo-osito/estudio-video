# Cerebro de guiones

Todo lo que hay que saber para escribir los guiones de los orgánicos de Max (TikTok e Instagram). Se abre como
vault de Obsidian (abrir la carpeta `cerebro/`) o se lee en el repo. **Antes de escribir o cambiar un guion, leer
estas notas.** Si algo de acá contradice un guion viejo, manda el cerebro.

| Nota | Para qué |
|---|---|
| [[01 Quién es Max hoy]] | Cómo se presenta, qué hace, qué NO decir. **Lo primero.** |
| [[02 Narrativa]] | La historia que cuenta la cuenta, la serie del reto y su arco de 30 días |
| [[03 Audiencia]] | A quién le habla y qué le duele |
| [[04 Pilares]] | Los 5 temas, para qué sirve cada uno y ejemplos |
| [[05 Voz en cámara]] | Cómo habla Max: palabras, ritmo, lo que suena a IA |
| [[06 Cómo se graba]] | Modos de cada párrafo (a cámara, voz en off, pantalla, sin hablar) y el plan de tomas |
| [[07 Reglas del guion]] | Ganchos, estructura, revisión antes de publicar un guion |
| [[08 Datos reales]] | Historias, números y casos de verdad que Max va dejando. **Sin esto, los guiones quedan con [corchetes].** |
| [[09 Banco de ideas]] | Ideas sueltas para las próximas tandas |
| [[Bitácora]] | Qué cambió en el cerebro y por qué |

## Cómo se usa
1. Max cuenta algo (por chat o en la nota de un video) → va a [[08 Datos reales]] o a la nota que corresponda.
2. Al armar una tanda: leer 01 → 07, sacar ideas de 09 y datos de 08, escribir en `semillas/*.json` con el formato de
   [[06 Cómo se graba]], cargar con `herramientas/sembrar.mjs` (nuevas) o `herramientas/actualizar.mjs` (existentes).
3. Después de publicar: lo que funcionó o no (retención, comentarios) se anota en [[Bitácora]] y se ajustan las reglas.
